## Chain behavior (verified live)
- text_chain = groq:llama-3.3-70b → gemini (keys) → cloudflare
- vision_chain = gemini (keys) → cloudflare (groq vision only if AI_VISION_GROQ_MODEL set — Groq has NO vision models, live-verified)
- Broken provider → auto next provider ✓ (tested: invalid Gemini key → groq served)
- Blocked gemini key → skipped ✓ (cache ai_gemini_key_blocked_{md5})
- Real vision call: provider_used=gemini:AIzaSyA5 ✓
- Agent chain: groq agent → [groq:llama, gemini] ✓
