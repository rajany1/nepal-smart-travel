# 2026-08-28 · Cold-start splash speed fix (Flutter)

**Problem:** App ka splash (cold start) kam 1 min samma load hune, UX kharsi.
**Root cause:** `mobile_app/lib/main.dart` le `runApp()` aagi (`await`) garthe:
- `authProvider.initializeAuth()` — session restore + network
- `localizationService.init()` → `getTranslations()` (network)
- `pushService.initialize()` → native `requestPermission()` dialog + `getToken()` (network)

Sabi `await` pura na huee native (platform) splash frozen — permission dialog / slow link le
1 min+ hang.

**Fix:**
1. `main.dart`: `runApp()` ab turunta (Firebase init pachi matra), ra heavy bootstrap
   `unawaited(pushService.initialize())` + `unawaited(localizationService.init())` background
   ma defer. `await authProvider.initializeAuth()` main bata hatyae — flush splash
   (`AuthInitializationWrapper._init`) le auth routing own garchha.
2. `splash_screen.dart`: `_init` ma hard 12s `.timeout()` (network stall bhaye pani splash
   kabhi hang hudaina — login/home ma fallback), ra branded splash (travel_explore icon +
   appName + tagline) banaye. Har `await` pachi `if (!mounted)` guard.
3. main.dart ko duplicate `import localization_service.dart` hatyo (duplicate_import).

**Gotcha note:** AuthProvider `_isInitialized` guard — splash le initializeAuth call garchha,
main bata hoina. PushNotificationService singleton factory, `initialize()` idempotent.
`flutter analyze` duita file: "No issues found!" (pura project 0 errors, ~446 pre-existing
warn/info — unchanged).
