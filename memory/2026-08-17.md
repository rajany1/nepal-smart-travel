# 2026-08-17 — Curated Routes → Trekking + Flutter App

## What was built

User asked: make curated routes work for TREKKING + the original plan (itineraries), and build it in the Flutter app with map integration.

### Backend (Laravel)
- **Migration** `2026_08_17_000000_add_trekking_fields_to_curated_routes`: `route_type` (itinerary|trekking, index), `difficulty` (easy|moderate|challenging|hard, index), `max_altitude_m`, `total_distance_km`, `elevation_gain_m`, `starting_point`, `ending_point`, `track` (json — array of `{lat,lng,name}`).
- **CuratedRoute model**: fillable/casts updated + `trackPoints()` (accepts `{lat,lng,name}` maps OR `[lat,lng]` pairs), `difficultyLabel()`, scopes `type()`/`difficulty()`, consts TYPES/DIFFICULTIES.
- **API**: `App\Http\Controllers\Api\RouteController` — `GET /api/v1/routes` (filters: type, difficulty, q; limit) + `GET /api/v1/routes/{id}` (adds `waypoints`, `track`, `places[]` with lat/lng/rating/category/image). Registered in api.php BEFORE auth group (public).
- **Admin CRUD**: controller validation + blade modal got: route type select, difficulty select, max altitude, distance, elev gain, start/end point, track textarea ("lat,lng,Name" per line or JSON). Edit JS loads track back to textarea.
- **Seeder** `CuratedRouteSeeder` (hooked into DatabaseSeeder): EBC Trek (hard, 14d, 5644m, 130km, 17 GPS points), ABC Trek (moderate, 8d, 4130m, 110km), Poon Hill (easy, 5d, 3210m, 55km), + KTM Valley Heritage Circle & Pokhara Lakeside (itineraries). updateOrCreate by slug — safe re-seed.
- **Web**: routes list cards show Trekking/Itinerary badge + difficulty/distance/altitude chips; route detail adds stat grid (distance, altitude, elevation, start→end) + **Leaflet map** (OSM tiles, polyline + numbered markers, `@push('head')`/`@push('scripts')` — NOTE layout has NO `@stack('styles')`, only 'head') + numbered trail waypoint list.

### 🐛 BOM BUG FOUND & FIXED (important!)
- `backend/routes/api.php` had a **UTF-8 BOM** at byte 0 → PHP echoed it on EVERY request → every API response started with `EF BB BF` → would break Dart `jsonDecode` in the app (silently broke offers/places too). Removed BOM. Scanned all non-vendor PHP files: 0 remaining.

### Flutter
- `core/models/route_model.dart`: `CuratedRouteModel`, `RouteTrackPoint`, `RoutePlaceModel`.
- `core/api/api_client.dart`: `getRoutes({type,difficulty,search,limit})`, `getRouteById(id)`.
- `providers/route_provider.dart`: fetchRoutes (filters), fetchRouteDetail, registered in main.dart MultiProvider.
- `features/routes/routes_screen.dart`: filter chips (All/Trekking/Itineraries + difficulty), route cards (gradient header, badges, stats), RefreshIndicator.
- `features/routes/route_detail_screen.dart`: gradient header w/ stats, flutter_map (OSM tiles) polyline + numbered markers from track, stops (→ PlaceDetailsScreen), trail waypoints list. Named route `/routes` in main.dart.
- Home screen: "Routes" quick action (Icons.hiking) + "Routes & Treks" horizontal strip section (`_RoutesStrip`/`_MiniRouteCard`).
- NearbyMapScreen: "Routes" button under map-mode toggle (top-left, below it).

### Gotchas
- `Icons.route_off` doesn't exist → use `Icons.map_outlined`.
- flutter_map v7: Marker width/height + child widget for numbered markers works fine.
- Track points stored as JSON objects `{lat,lng,name}` (not lat-lng pairs) — cleaner for both web Leaflet + Dart.
- `track` cast 'array' → `trackPoints()` guards empty.
- Admin track textarea uses comma-join `p.lat,p.lng,p.name`.
